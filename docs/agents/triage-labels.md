# Triage 标签

相关技能使用五种规范 triage 角色。下表将这些角色映射到本仓库 issue tracker 使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库中的标签    | 含义                       |
| -------------------------- | ----------------- | -------------------------- |
| `needs-triage`             | `needs-triage`    | 需要维护者评估该 issue     |
| `needs-info`               | `needs-info`      | 等待报告者提供更多信息     |
| `ready-for-agent`          | `ready-for-agent` | 规格完整，可交由 AFK agent |
| `ready-for-human`          | `ready-for-human` | 需要人工实施               |
| `wontfix`                  | `wontfix`         | 不会处理                   |

当技能提及某个角色时，例如“应用 AFK-ready triage 标签”，使用上表中对应的本仓库标签字符串。

如需匹配实际使用的词汇，可编辑右侧一列。
